# PosterWords — Learn Mandarin Chinese Through Beautiful Poster Cards

[![Download on the App Store](https://img.shields.io/badge/Download-App%20Store-blue?style=for-the-badge&logo=apple)](https://apps.apple.com/app/posterwords-learn-mandarin/id6771689623)

**PosterWords** turns learning Chinese into collecting beautifully designed poster cards. Describe any real-life scene, and AI instantly generates a complete learning bundle — words, phrases, and sentences with tone-marked pinyin, native audio, and smart spaced repetition review.

🌐 **Website**: [posterwords.pages.dev](https://posterwords.pages.dev/)

## Features

- **AI Scene Generation** — Turn any situation into a coherent Chinese lesson
- **HSK 1–9 Levels** — From beginner to near-native (HSK 3.0 standard)
- **Poster-Style Cards** — Character-first design that feels like collecting art
- **Smart Spaced Review** — Leitner boxes + forgetting curve for efficient memorization
- **Hanzi Stroke Writing** — Guided stroke-by-stroke character practice
- **Native Audio & Pinyin** — Tap any card for natural pronunciation
- **Daily Streak** — Build learning habits with streak protection
- **19 Languages** — Interface available in 19 languages
